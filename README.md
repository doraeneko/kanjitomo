# kanjitomo

A Japanese kanji learning app for Flutter: draw a character to look it up
(via a custom-trained recognition model), then track your reading/writing
mastery of both individual kanji and the compound words they appear in
through a spaced-repetition (SM-2) review system.

- **[FEATURES.md](FEATURES.md)** — a user-facing tour of every screen.
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — the codebase's layering, the
  recognition pipeline, the database schema, and the review engine.
- **[plan.md](plan.md)** — the original design note for the Learning
  section's four-axis (A/B/C/D) review rework; still useful background for
  *why* the review engine is shaped the way it is.

## Getting started

```
flutter pub get
flutter run
```

Requires Flutter 3.35+ / Dart 3.9+ (see `pubspec.yaml`'s `environment.sdk`).

### Tests

```
flutter test
```

### Static analysis

```
flutter analyze
```

### Building

```
flutter build apk --debug   # or --release
```

## Where the data comes from

Every bundled asset under `assets/` — the ONNX recognition model and every
JSON file (kanji readings/meanings, JLPT levels, stroke paths, compound
words, example sentences, ...) — is generated by a separate sibling Python
project, **kanjirec**, and is read-only from kanjitomo's point of view.
Regenerating any of this data means running the corresponding script in
that project and copying its output into `kanjitomo/assets/`.
